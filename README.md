## 🏆 Highlight Projects

### 🛍️ E-Commerce Web Application
A fully responsive online shopping platform built with ReactJS. Users can browse products, add items to a cart, and go through a checkout workflow. Focused on component-based architecture.

**Tech Stack:** ReactJS • JavaScript • HTML/CSS  
🔗 [View Repository](https://github.com/swetima-kumari/E-Commerce-web-application-)

---

### 🌤️ Weather Dashboard
A real-time weather tracking app that fetches live weather data for any city using the OpenWeatherMap REST API. Built with vanilla JavaScript using async/await and Promises for smooth, error-free data fetching.

**Tech Stack:** JavaScript • REST API • HTML/CSS  
🔗 [View Repository](https://github.com/swetima-kumari/Weather-Dashboard)

---

### 📈 Stock Price Prediction (LSTM)
A deep learning project using stacked LSTM layers to predict future stock closing prices from historical time-series data. Features an end-to-end pipeline with data normalization and 60-day sequence modeling.

**Tech Stack:** Python • TensorFlow • LSTM • Pandas  
🔗 [View Repository](https://github.com/swetima-kumari/stock-price-lstm)
